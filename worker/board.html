        Collector setup & reporting

        Connect a host with a standard Docker Compose package. Review the files, deploy under /srv/docker/docker-dashboard-collector, and wait here for its first report. The collector runs as your user; the restricted socket proxy runs as container root.

        Maintenance mode

        Pause automatic ntfy alerts and recoveries for this host. Reports, health, and activity remain visible. Notifications resume automatically when the timer ends.

        Update collector

        Replace only collector.py and restart the collector. Your credentials, Compose file, and user permissions are kept. Run as the installation owner; sudo is used for Docker if needed. A subsequent report confirms the version.

        Default directory: /srv/docker/docker-dashboard-collector. For another path, export CROWSNEST_COLLECTOR_DIR before running.

        Replace reporting token

        Prepare a new configuration and apply it on the host within ten minutes. The current token stays valid until the first successful report using the replacement. This replaces the host token; platform service access is unchanged.
