# Crowsnest brand assets

`crowsnest-mark.png` is the transparent crow emblem used in the dashboard header, empty state, and browser favicon. It is included in the source and embedded in the Worker build; the dashboard does not depend on a remote image host.

The interface pairs slate surfaces with warm ivory and copper, and uses separate labeled green, amber, and red status colors. See [interface conventions](../../DESIGN.md).

The emblem was generated and refined with an image-generation tool. Its provenance is embedded in the PNG metadata. When replacing the asset, retain a transparent background, a clear silhouette at small sizes, and truthful source metadata. Brand changes should be reviewed alongside the interface.
