# Owner access surface

Mode: Operate. Extend the existing Crowsnest world for a single owner, using the confirmed product scope. No new brand assets or replacement visual system.

## Working model

Visual thesis: a quiet slate workspace with the existing crow and copper action color, where the form is the main task.

Content plan: recognizable brand, sign-in or owner-setup heading, fields, one primary action, contextual server-code help, and password recovery.

Interaction thesis: preserve typed username across retries; make loading and errors readable without moving the form; honor reduced motion and the established focus treatment.

## Direction contract

THESIS: Get the owner into their fleet with a short, explicit form. No marketing claims or decorative dashboard preview.

OWN-WORLD: Inherit `worker/board.css` tokens, the crow mark, system interface type, quiet separators, and copper actions.

STORY: A fresh installation requires a short-lived code generated on the server. An existing owner signs in with their username and password. Recovery requires a different server-issued code and invalidates old browser sessions.

FIRST VIEWPORT: On desktop, a compact brand and explanatory column sits beside a 26rem form. On mobile, brand and form stack in reading order with the primary action visible after the fields.

FORM: A task form inside an established app identity; this precisely scoped access flow is code-first, without a concept-seed round.

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
