# Roadmap

The current release includes clearer enrollment, ntfy subscription help, timed maintenance, Compose grouping, collector versions, and container details.

Longer-term candidates:

- **Resource usage:** bounded CPU and memory sampling, clear sampling intervals, limits for large fleets, and explicit proxy permissions. Start with current usage before considering historical storage.

These are planning items, not available features or promised release dates. Existing collectors must remain compatible as metadata expands.
