# Roadmap

The current release includes collector enrollment and updates, standalone owner access, ntfy policy and maintenance controls, Compose grouping, container details, host groups, and optional CPU/memory measurements with 24-hour workload history.

Longer-term candidates include longer configurable retention and resource-threshold notifications. They require explicit storage limits and measured collection costs before release.

These are planning items, not available features or promised release dates. Existing collectors must remain compatible as metadata expands.
